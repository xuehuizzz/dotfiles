<h1 align="center">服务器日常问题排查</h1>

### 排查du和df对不上的情况
```bash
lsof | grep deleted                     # 揪出"被删但还活着"的文件
: > /proc/<pid>/fd/<fd>                 # 一行截断，磁盘立刻释放
# 真搞不定就 systemctl restart <service> —— 最干净的运维口诀
```
> ⚠️ `rm -rf /proc/<pid>/fd/<fd>`是错的！`/proc/.../fd/...` 是符号链接，`rm` 删的是链接、不是底层 inode。要释放空间得 truncate 那个 fd

### 排查后端通不通 502/504
```bash
nc -zv <ip> <port>          # TCP 通不通（一行 Connection refused = 后端挂）
curl  -I <url>               # 只看响应头，5 秒判断 5xx / 4xx
curl -v <url>               # 端到端：SSL 握手 / 代理 / 超时全看清
# 老式 telnet <ip> <port> 作为备用
```
> ⚠️ `nc -zv` 中 `-z` 是 zero-IO 模式（只连不发）。千万别漏了 `-z`

### 磁盘 IO 100%，谁在写？
```bash
iostat -xz  15              # 每秒打印块设备 await / util%，看清谁 100%
iotop -oP                    # 实时看哪个进程在写（最直观）
# 找进程后：
pidstat -d 15  -p <pid>      # 看那个进程每秒读写块数
```
> ⚠️ `iostat` 不加 `-x` 只看基本 CPU 比例，看不到 await（毫秒）/ %util / w/s / wkB/s 这些救命字段

### 端口被占了？秒级定位
```bash
lsof -i :8080                         # 老派但准：列进程 / PID / 用户
ss -ltnp  'sport = :8080'              # 现代替代（更快，云上更稳）
kill -9 $(lsof -t -i :8080)           # 一键杀
```
